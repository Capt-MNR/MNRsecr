The approved first Main mockup defines the composition and proportions of the Main home surface. Functional data and Secretary behavior may remain backed by the existing implementation, but card dimensions, spacing, ordering, and visible sections must be rebuilt to match the mockup rather than preserved from the old layout. The visual direction should also make the intelligent secretary the primary actor, not a generic dashboard. Main is intended as a fixed, glanceable office surface rather than an outer scrolling dashboard; assistant activity, proactive behavior, and AI depth are user-controlled local preferences.

**Why:** Recoloring the previous oversized layout was not sufficient; the user explicitly compared geometry and expected the mockup composition to be reproduced, then noted that the resulting look still did not communicate intelligence.

**How to apply:** When changing Main UI, compare the compact summary row, central chat panel, asymmetric Today/Quick Actions split, and Recent Activity composition against the approved mockup before adding new cards or restoring older spacing. Prefer truthful, data-backed assistant status and natural-language suggestions over generic CRUD labels.
